# Server modules

Every module lives in `modules/` and keeps its own README and LICENSE. Credit for each belongs to its author as stated there. Where a module came from an upstream project, the upstream is named. Status words are explained in the main README.

| Module | What it does | Origin / credit |
| --- | --- | --- |
| mod-account-bound | Account-wide achievements, mounts, companions, titles, reputation, professions and friends shared across characters | see its README / LICENSE |
| mod-auctionsim | Fills and maintains the auction house from price data of a live 3.3.5a economy | see its README; no LICENSE file |
| mod-azeroth-friend | Autonomous AI companion for playerbots, with a Python reasoning bridge and a client HUD | see its README; no LICENSE file |
| mod-character-order | Players reorder their characters on the account from in game | see its README / LICENSE |
| mod-dungeon-clear | Tank playerbots lead the party boss to boss through a dungeon | see its README / LICENSE |
| mod-forever-dungeon-journal | Retail-style dungeon journal (module plus addon) | see its README / LICENSE |
| mod-holiday-control | Run holidays and world events from the config file, plus custom events | see its README / LICENSE |
| mod-individual-progression | Per-player progression through expansion tiers | see its README / LICENSE |
| mod-llm-chatter | Roleplay conversation engine for companions and playerbots | see its README / LICENSE |
| mod-lost-legendaries | Puts lost legendary items back in the game | see its README / LICENSE |
| mod-mana-loot-pet | Sends a vanity companion to loot a fresh corpse | see its README; no LICENSE file |
| mod-mana-speedflying | Flying mount speed varies with how you fly; server side of the client's speedflying module | Manastorm, see CREDITS.md; no LICENSE file |
| mod-open-world-party-scaling | Raises open-world difficulty for parties | see its README / LICENSE |
| mod-playerbots | Player bots | upstream mod-playerbots project (see its LICENSE) |
| mod-playerbots-city-life, mod-playerbots-pvp-life | City and world-PvP behavior for bots | iCore (per its README) |
| mod-questie-bridge | Lets Questie-335 follow live quest data | see its README; no LICENSE file |
| mod-raid-clear | Teaches playerbots boss and trash handling | see its README / LICENSE |
| mod-retail-druid-forms, mod-retail-shaman-totems, mod-retail-warlock-pets | Retail looks for druid forms, shaman totems and warlock demons, picked in the Transmogrify window | see their READMEs / LICENSE |
| mod-transmog, mod-transmog-plus | Transmogrification; the Plus version is slot based | mod-transmog is AzerothCore's; Plus is the adapted slot-based version |
| mod-worgoblin-high-elf | Worgen, Goblin and High Elf race support (WHE) | Medviten; its DBC tool is Foe's DBCTool (MIT) |

Modules without a LICENSE file are listed in `UPSTREAM-LICENSES.md`.
